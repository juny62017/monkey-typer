# Typing Monkey

A simple typing speed test website to check how fast and accurately you can type.

## About

Typing Monkey is a basic web project. It lets users type a given paragraph and calculates their typing speed (WPM), accuracy, mistakes and total characters.

The goal of this project was to keep things simple and clean while implementing core logic step by step.

## Features

* 30 second typing test
* Calculates WPM (words per minute)
* Shows accuracy percentage
* Counts mistakes
* Tracks total characters typed
* Reset button to restart test
* Random paragraph each time

## How to Use

1. Open the website
2. Click on **Start Test** or start typing directly
3. Type the paragraph shown on the screen
4. After 30 seconds, results will be displayed
5. Click **Reset** to try again with a new paragraph
